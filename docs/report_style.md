# Report style guide

For anyone, person or agent, drafting or editing the report (Spanish, LaTeX). These are the
conventions of the H1 proposal (91/100). The proposal's LaTeX lives outside this repo.

## Voice

- **Written prose, not notes or speech.** Use full sentences joined by connectors ("Por un
  lado… mientras que…", "Además", "En primer lugar", "pues", "A partir de esto").
- **No colons, semicolons or dashes as punctuation** in body text. Restructure the sentence
  with a connector instead. Itemize is fine where the content is a list, such as the
  models or the plan.
- **Short paragraphs.** Each paragraph carries one idea, and they read as a narrative from
  one to the next.
- **Concise.** H2 is 3–4 pages. Cut before adding.
- **Detail fits the section.** The problem description has no implementation details. The
  methods section is concrete; the H1 feedback asked for more detail on what each method
  is.
- **Nothing the team hasn't agreed on.** That covers extra analyses, statistical tests and
  references.

## LaTeX

- **Paragraph endings.** Every paragraph ends with `\\` followed by a blank line. Never
  remove them.
- **Numbers.**
  - Decimal comma: `0,283`.
  - Percent with no space: `92\%`.
  - Thousands with a dot: `8.341`.
- **Terms.**
  - English terms go in italics: `\textit{cold-start}`, `\textit{blending}`,
    `\textit{Random}`, `\textit{Most Popular}`.
  - The other models have Spanish names: Recencia, CF + recencia, Regresión logística.
- **Cross-references.** Use `Sección~4`, `Tabla~\ref{tab:...}` and `Figura~\ref{fig:...}`.
- **Floats** use `[htbp]`. Tables come from `results/*.tex`, generated by the scripts. Paste
  them, never retype the numbers.
- **Captions** are short and descriptive. The explanation goes in the paragraph that cites
  the table or figure, not in the caption.
- **"Tabla" and "Figura".** In H1 the course template printed "Table"/"Figure". An untested
  fix for the preamble is below. Check the PDF after compiling.
  ```latex
  \addto\captionsenglish{\renewcommand{\figurename}{Figura}\renewcommand{\tablename}{Tabla}}
  \addto\captionsspanish{\renewcommand{\figurename}{Figura}\renewcommand{\tablename}{Tabla}}
  ```
- **Bibliography.**
  - Use `\bibliographystyle{unsrt}` with `references/recsys.bib`, numbered by order of
    appearance.
  - Each entry costs space at the end of the document, so cite only what earns it.
  - `unsrt` ignores the `url` field. Put URLs in `howpublished` with `\texttt{...}`.

## Numbers in the text

- **Traceable.** Every number comes from a script output, either a file in `results/` or
  the printed output of `scripts/estadisticas.py`.
- **Paper or replication.** Always say which it is, as the H1 feedback asked. For example,
  "0,283 según el paper y 0,286 en nuestra réplica".
- **Supported by an exhibit.** A number that carries the argument (for example, the 92\% of
  correct jobs with recent activity) is backed by a table or figure, as the H1 feedback
  asked.

## Figures

- **Simple and descriptive.** Histograms, bars and lines in matplotlib, with Spanish titles
  and axis labels with units, and no elaborate transformations. They come from
  `scripts/figuras.py`.
- **Earns its space.** A figure whose point fits in one sentence is cut.

## Submission

- **File name.** Name the PDF `G5_<entrega>_recsys.pdf`. H1 was `G5_propuesta_recsys.pdf`.
- **Repo link.** Include the GitHub link in every deliverable. H1 lost points for this.
- **Deadline and length.** Submit on Canvas by 20:00. H2 is 3–4 pages, and annexes are
  allowed. The paper is ≤ 8 pages including references, with a bonus for writing it in
  English.
